HOW TO READ THIS
  EXACT     reproduced outright - use it.
  SCALED    right observable, constant normalisation offset. Fine:
            the paper compares nominal against systematic with the
            same code on both sides, so a constant factor cancels.
  MONOTONE  same ordering, non-constant offset. Usable for SHAP and
            for a tagger, but say so in the text.
  WEAK/FAIL do not use this feature until the definition is fixed.
